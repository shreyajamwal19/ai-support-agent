# Data directory

- `raw/twcs.csv` — NOT committed (see repo root `.gitignore`). Download from
  https://www.kaggle.com/datasets/thoughtvector/customer-support-on-twitter and place at
  `data/raw/twcs.csv`. Licensed under the Kaggle dataset's own terms.
- `processed/` — generated by `scripts/01`-`scripts/03` + `src/data/reconstruct.py` +
  `src/data/split.py`. Not committed (regenerable, and large).
- `golden/` — the 200-example golden evaluation set IS committed (small, no raw dataset
  redistribution — only reconstructed pair text + labels).
- `samples/` — reserved for small illustrative samples if needed; currently unused.
